GOVERNED PROTOTYPE

Sovereign control plane

Follow an approved stack from purpose-bound access to a verified export.

Software-simulated attestation · Mock inference · Local demo personas. This prototype does not provide hardware attestation, host isolation, physical memory erasure, or production authentication.

Enable the local demonstration

Start Vega with demo endpoints enabled. Your workspace stays empty until you prepare the synthetic fixture.

$env:VEGA_ENABLE_DEMO_ENDPOINTS = "1"
python run_vega.py

1. Prepare and approve

Prepare synthetic data, then record approvals as Model Custodian and Security Officer. Activate as Model Custodian and issue a lease as Data Owner.

Persona switching simulates different people for the local demonstration. It is not a sign-in system.
